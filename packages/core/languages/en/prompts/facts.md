FACT CHECK.
Find the verifiable claims (numbers, dates, names, versions, quotations, cause and effect) and compare them with the sources.
For each one call "annota" with:
- citazione: the claim, copied exactly;
- esito: "verificato" if a source confirms it, "da_verificare" if a source says something else or the name looks misspelled, "senza_fonte" if no source mentions it;
- spiegazione: what the source says, in one line;
- correzione (optional): the right value, if the source gives it.
A claim followed by a footnote [^n] has a source. Opinions are not facts. Write the explanation in English.
