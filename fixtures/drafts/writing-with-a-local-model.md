# Writing with a local model

For a year I have been writing with a language model that runs on my own laptop. Nothing leaves the machine, and that changes how I use it more than I expected.

## What changes

The first thing you notice is the speed. A model with thirty-five billion parameters answers in a few seconds, because it only activates a small part of its weights for each word. On a Mac with 64 GB of memory it uses about 22 GB, which leaves plenty of room for everything else.

The second thing is privacy. When the draft never leaves the computer, you stop worrying about what your sending to a server somewhere. Its a small relief, but it affects every session: I paste whole chapters without thinking twice.

The model is not perfect. It misses some mistakes, and their are days when it suggests changes that make the text worse. But it never writes in my place. It points at a sentence, explains the problem, and leaves the decision to me.

## Conclusion

A local model is not a replacement for an editor. It is a patient first reader that is always available, costs nothing per page and keeps the text where it belongs: on the writer's desk.
